# 🐍 Retro Snake Game in Pygame

A simple and fun classic Snake game built with Python and the **Pygame** library. Control the snake, eat apples, grow longer, and try not to crash into the walls or yourself!

---

## ✨ Features

* 🎮 **Dual Control Schemes:** Play using the classic Arrow keys or standard `W`, `A`, `S`, `D` keys.
* 🍎 **Upscaled Visuals:** The snake and food blocks are upscaled to a crisp 20x20 pixels for better visibility.
* 🔄 **Quick Restart:** No need to relaunch the script — just press `R` to play again instantly after a game over.
* ⏱️ **Smooth Arcade Feel:** Optimized tick-rate for that classic, responsive arcade movement.

---

## 🚀 Getting Started

### 1. Prerequisites
Make sure you have Python 3 and the Pygame library installed on your system.

### 2. Installation
If you don't have Pygame installed yet, open your terminal or command prompt and run:

  `pip install pygame`

### 3. Running the Game
Clone this repository and run the main script: 

`git clone [https://github.com/Timofey6400/Snake.git](https://github.com/Timofey6400/Snake.git)`
**now:**
`cd Snake`
**then:**
`python main.py`
* **💡 Note: If your file has a different name, like snake.py, make sure to use that name instead of main.py.**
